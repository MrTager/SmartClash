# v0.7.1 · 一次授权后台服务

系统代理和 TUN 改为共用经过签名校验的 root 后台服务。首次安装时确认一次 macOS 管理员授权，之后开启、关闭、停止、退出、重开及重启后使用同一服务，不保存密码。

后台服务仅接受安装用户及指定签名的客户端，双方校验 XPC 对端签名；仅支持固定网络操作，不提供 shell 或任意可执行文件入口。TUN 配置只接受本应用生成的受限字段，规则集仅能写入固定目录。关闭 TUN 仍卸载其内核服务并恢复路由，后台服务保持安装。

旧版系统代理备份和 TUN 服务可通过同一恢复入口清理。首次安装授权取消后不新建代理恢复记录、不修改系统代理；服务不可用或被系统设置停用时显示提示，不反复请求密码。

本地 ad-hoc 构建更新后签名变化，首次使用新版可能需要再次安装授权。完全卸载后台服务的命令见 README。
