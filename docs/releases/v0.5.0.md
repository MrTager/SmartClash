# SmartClash v0.5.0 — Intel macOS 预览版

适用：Intel x86_64，macOS 13 及以上。应用版本 0.5.0，build 7。

## 本次更新

- 可视化实际生效的单跳 / 多跳路径、跳数、协议及备用状态。
- 低延迟、高速、AI 三种线路模式；高速使用限量下载实测，AI 模式验证 OpenAI API 可达性。
- 实时上传/下载速度、60 秒曲线、本次运行与历史累计流量。
- 分离前台操作和后台监控，修复持续转圈与停止按钮被锁；网络检测支持取消。
- 全部 / 单节点延迟测试、延迟排序、本地 Clash Verge 配置导入及应用 Logo。
- 修正 Swift 编译、Intel 打包与配置序列化兼容问题；提供安全安装/更新脚本。

## 验证情况与限制

- 2026-11-04 在 Intel macOS 上完成 62 项测试，包含只读实机流量集成与离线 UI 渲染；应用包通过架构与 ad-hoc 签名校验。
- 安装包为本机构建的预览版，未进行 Developer ID 签名或 Apple 公证；不是生产稳定版认证。
- 实际 root TUN 接管、管理员取消授权、全局路由恢复及长期连接仍需继续实机验收，不能用编译/单元测试结果替代。
- AI 检测只确认 API 网络可达，不保证 ChatGPT 网页登录、账号或地区资格。出口切换不能迁移已有 TCP 会话。
- 高速模式每轮最多抽测 3 个候选、约消耗 3 MiB 流量；短时测量不保证持续带宽或全局最优。
- 流量以内核上报为准，测速/后台探测可能计入；不是全电脑流量或服务商账单。历史累计从本功能开始记录。
