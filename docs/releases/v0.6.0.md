# SmartClash 0.6.0

新增原生 3D 地球，显示代理节点与活跃请求目标之间的弧线和流向动画。支持拖动旋转、滚轮缩放、回到当前节点，以及从请求列表聚焦单条连接。概览、节点和链式代理页面均可查看。

新增「实时流量」页面和侧栏常驻上传/下载速度，显示最近 60 秒曲线、本次内核累计与历史累计。流量流断开会重连，并可根据内核累计计数恢复速率。

连线使用每条连接实际报告的节点链，出口切换后保留旧连接归属。位置以目标 IP 为优先；内核未提供目标 IP 时使用本机 DNS 估算，并明确标记。IP 地理位置为近似值，连线表示地理关系，不是物理路由追踪。位置查询仅向 ipwho.is 发送公网 IP，结果在本机缓存 24 小时。

内置 Natural Earth 公共领域底图，不依赖地图密钥或在线瓦片。支持 Intel macOS 13 及以上。
