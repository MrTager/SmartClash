# SmartClash 0.7.0

新增独立的规则代理、全局代理、直连流量模式，概览、应用菜单和菜单栏均可切换。模式与低延迟、高速、AI 选路策略独立，选择会持久保存。全局代理跟随智能出口，直连不需要订阅节点。切换后关闭旧连接，使新会话使用新模式；失败尝试回滚。

接入 GMOogway/shadowrocket-rules 的 DIRECT、PROXY、REJECT 模块，每小时自动更新，可手动刷新。规则下载、条目数校验、转换完成后保存完整缓存，失败保留旧规则并重试；Mihomo 不支持的 URL 正则、User-Agent 和无效条目会统计为跳过。规则模式无缓存且下载失败时不会静默降级。

域名使用独立规则集加速匹配，关键词和 CIDR 使用 classical 规则集；通过受令牌保护的本机服务热更新，兼容 TUN，无需为更新规则再次授权或重启内核。节点验证使用独立 PROBE 监听，避免规则直连误判代理节点可用。

应用运行期间才会定时更新；规则源的 jsDelivr 备用镜像可能滞后。实际 root TUN 接管路径仍需管理员授权实机验收。
