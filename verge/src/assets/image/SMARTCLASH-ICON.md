# SmartClash icon

The SmartClash icon was generated with image_gen on 2026-11-04. The master
1024 × 1024 PNG is `smartclash.png` in this directory. Desktop icon variants
are in `src-tauri/icons/icon.ico` and `src-tauri/icons/icon.icns`. The active
desktop source owns these assets independently of the removed clients.

The artwork is a rounded cobalt blue tile with a continuous white to cyan
S-shaped network path and three nodes.
